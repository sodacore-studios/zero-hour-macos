# Changelog

## 0.3 release line — 2026-10-21

- Restore real-time simulation independently of ordinary render slowdown.
- Preserve command readiness and CRC propagation during bounded catch-up.
- Add authenticated, signed automatic GitHub updates and recoverable app replacement.
- Add isolated tests, coverage reports, ARM64 release automation and English delivery documentation.
- Keep the Abrams prototype outside the release.

See [maintained release notes](docs/RELEASE_NOTES.md) and [verification status](docs/VERIFICATION.md).

## 0.2.1 — 2026-10-14

- Native launcher with configurable server, invitation and optional relay.
- Private guest authentication and matching client path.
- Fullscreen, WASD, silent arrow keys and selectable render resolutions.
- Ultrawide HUD/menu scaling, extended zoom and terrain coverage.
- Additional 6016 × 3384 and 7680 × 2160 resolutions.
- Five-second sodacore studios opening card and supplied app icon.
- Local packaging with user-provided game files.
- HTTPS/WSS and UDP relay deployment, protocol checks, templates and operations documentation.
