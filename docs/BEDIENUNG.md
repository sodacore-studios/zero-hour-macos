# Operation

The maintained English guide is [Installation and operation](INSTALLATION.md). It covers game-file setup, resolutions, input, online configuration, updates and rollback. This path is retained for older links.

## Mouse controls

The launcher enables **Left-click selects; right-click moves / attacks** by default,
including when loading older settings. Left-click or drag with the left button to
select units, then right-click terrain to move or an enemy to attack. Building
placement and explicit abilities keep the game's existing confirmation/cancel
behavior. Right-button camera dragging is disabled in this mode; use WASD, arrow
keys or edge scrolling. Uncheck the option and restart the game for classic mouse
controls. Changes apply on the next game launch.
